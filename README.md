# Holo Music

**Holo Music** — лёгкий музыкальный плеер в стиле Android 4.x (Holo).

Библиотека сканируется через MediaStore, сторонние библиотеки не используются.

## Особенности

- Минималистичный интерфейс в стиле Holo (Android 4.x)
- Сканирование локальной музыки через MediaStore
- Поддержка плейлистов, очереди, избранного
- Эквалайзер
- Работа без интернета и сторонних зависимостей
- Поддержка Android 4.1+ (API 16)

## Установка

Скачайте APK из раздела [Releases](https://github.com/SkobarPSK/HoloMusic/releases) или файл `HoloMusic-1.0-beta.apk` в корне репозитория.

## Сборка

Проект использует стандартный Android Gradle Plugin.  
Минимальный SDK: 16  
Target SDK: 29  
Compile SDK: 30

```bash
./gradlew assembleRelease
```
